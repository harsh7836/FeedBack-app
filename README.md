# HeyFeedback App

HeyFeedback is a web application that allows users to submit and view feedback in a seamless and user-friendly manner. Built with Node.js, Express, and MongoDB for the backend.

## Features

- **Submit Feedback**: Users can submit their feedback through a simple form.
- **View Feedback**: Users can view all the submitted feedback.
- **User Authentication**: Secure login and registration system.
- **Real-time Updates**: The feedback list is updated in real-time.

## Technologies Used

- **Frontend**: React
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication**: JWT
